The scope stays active, so raw, control, direct forward, forge and engineIdentity remain refused until exit. Outside the scope a retained poisoned state is inert: `needsSynchronousGuard` is false and `beginSegment` takes the incumbent path, so OFF behavior is preserved.

Between tokens pending is always zero, so a poison cannot be introduced by a user `reset` call mid-flight.
