## Compatibility and caveats

- **Old identity-bearing reports no longer decode.** The derived record has a new required field. No prior full-model report exists and the report is not an artifact schema with a default or promotion path, so this is acceptable. Any earlier diagnostic report that may surface must not be presented as comparable to, or as qualifying under, the current gate.
- **Static coupling.** The per-forward table reads the divisor from the gate's declared candidate rather than from the context's candidate. Identity pins the context candidate to the same map, so the two cannot diverge in this tool. Passing the candidate into the table would remove the coupling if the gate is ever reused with another candidate.
- **No performance meaning.** This approval covers correctness qualification under normal concurrency only. Timings collected in that mode carry no TPOT claim and no quiet-environment assumption, and gainQualified stays false regardless of outcome.
