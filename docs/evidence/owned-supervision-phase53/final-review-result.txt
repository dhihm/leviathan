**Verdict: ACCEPT.** Both blockers are fixed correctly and the new tests exercise the actual failure paths rather than mocks of the result.

**Blocker 1, receipt before lock.** `Supervisor._write_receipt` now sets `receipt_written` only after the atomic link succeeds, and on failure records the error and the `receipt_write_failed` phase in state. `Supervisor._finish_after_receipt` releases the lock only when the receipt exists and the child status is known, then records the actual outcome under `cleanupResult`. `Supervisor._exit_code` returns nonzero whenever no receipt was written, with the interrupted path still taking precedence. Lock absence now implies a receipt exists, which is the property status needed.

**Blocker 2, best-effort echo.** `Supervisor._handle_line` isolates the echo write, disables echo after the first OSError or ValueError, and leaves log, progress and state writes untouched. The real-child test confirms the run still reaches success with all lines logged.

**Additional fixes checked and sound.** The guard flag is set at the top of each except branch, so a signal during error handling is recorded, not raised. The GO write to a closed pipe becomes an explicit abort whose exit evidence still comes from the Popen wait status. SIGCHLD is forced to default for the run and the prior disposition is restored, including SIG_IGN. The request/ready pairing is fail-closed in every malformed case, compares scopes exactly, and never consults the local clock. The exec-survival test now proves the identity assumption on a real owned child. The docstring now states honestly that log and state writes happen inside the window.

No new substantive failure introduced. Two non-blocking notes:

- **Timestamp parsing depends on Python 3.11 or later.** `parse_aware_utc` relies on `datetime.fromisoformat` accepting a trailing Z. On 3.10 or earlier a valid Z-suffixed readyUTC is reported as malformed and GO is withheld. This is fail-closed, so the risk is a confusing refusal, not an unsafe start. Either replace a trailing Z with the explicit zero offset before parsing, or document the interpreter requirement. The supervisor's own `utc_now` emits the Z form, so a parent that copies that format would hit this on an older interpreter.
- **`_install_signals` now always calls `signal.signal`.** Setting the SIGCHLD disposition happens even with handlers disabled, so `Supervisor.run` can no longer be invoked from a non-main thread. The CLI never does this and `main` does not catch the resulting ValueError. Only relevant if the class is embedded elsewhere.
